可复用的四个阶段

  1. Intake：读取输入与执行约束，确定适用范围。
  2. Migrate：在审计策略中选择，冻结候选快照。
  3. Validate：检查语义，再测暖态与实际部署模式。
  4. Export：只导出与已验证候选绑定的工作流。
